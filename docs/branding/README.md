# Plugin tiles

Proposal for the logos of the official plugins. The concept, the open
decision on third-party brand marks and the screenshot rules are in Phoedox
(project `phoedox`, page "Plugin logos and screenshots").

- `tiles-light.webp`, `tiles-dark.webp` – preview of all tiles
- `tiles/<plugin>.svg` – one tile per plugin (light, 128 px)
- `plugins.json` – category and Lucide icon per plugin (`old` = icon it replaces)
- `preview.html` – the preview sheet, open it in a browser

Regenerate with `node scripts/tiles.mjs`.
